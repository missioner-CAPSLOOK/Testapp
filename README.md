# CallRecorderTest

Тестовый проект для Android 13+.

## Что делает

- запускает foreground service;
- получает события состояния телефонного звонка;
- различает звонок в состоянии звонка/ожидания;
- автоматически запускает тестовую запись при переходе звонка в OFFHOOK;
- останавливает запись после IDLE;
- сохраняет файлы в приватной папке приложения:
  `Android/data/ru.example.callrecordertest/files/Recordings/`

## Важно

Эта версия записывает источник `MIC` (микрофон). Она предназначена именно для проверки автоматического запуска/остановки и поведения устройства.

Обычное Android-приложение не получает гарантированного доступа к полному аудио телефонного разговора (оба направления). Если в тестовой записи слышен только микрофон или запись получается пустой, это ограничение аудиополитики/прошивки, а не ошибка детектора звонка.

## Сборка

1. Открой папку в Android Studio.
2. Дождись синхронизации Gradle.
3. Build -> Build APK(s).
4. Установи APK на телефон.
5. Выдай все запрошенные разрешения.
6. Разреши приложению работу в фоне/без оптимизации батареи, если MagicOS этого попросит.
7. Сделай тестовый входящий и исходящий звонок.

## Для HONOR

На MagicOS могут действовать дополнительные ограничения фоновой работы. Если сервис останавливается, в настройках батареи для приложения нужно разрешить работу в фоне/автозапуск, если соответствующие пункты доступны на конкретной прошивке.

## Следующий этап

После теста можно добавить:
